# Contributing to AdnOS

First: **thank you.** AdnOS is at its very beginning, and early voices shape a project the most.

> [!NOTE]
> Everything here is **extremely early and subject to change**. Plans get rewritten, names can change, and whole
> components might be swapped for better ones. Please don't let that stop you. It's the best time to have an influence.

## Ways to help right now

- **Challenge the spec.** Read [docs/SPEC.md](docs/SPEC.md) and open an issue when something seems wrong, missing or overcomplicated.
- **Share experience.** If you've worked on Wayland compositors, Smithay, Rune, Android launchers or IMEs, mobile Linux
  kernels, OSTree images or Cloudflare Workers, your knowledge is gold.
- **Design.** Mockups and motion studies for Bayt, Itlala and Ruq'a are hugely valuable.
- **Remember webOS.** If you used a Palm Pre, Pixi, Veer, Pre 3 or TouchPad, tell us what made it feel the way it did.

## Ground rules

- **Be kind.** Disagree with ideas, never with people.
- **Small, focused changes.** One idea per issue or pull request.
- **License headers.** New source files start with an SPDX line (see [LICENSING.md](LICENSING.md)).
- **Upstream first.** When a fix belongs in a project we build on (Smithay, Rune, Waydroid and so on), we send it there.

## Tools, including AI

Use whatever tools help you do good work, AI coding agents included. You're responsible for what you submit:
understand it, test it, and make sure you have the right to contribute it.
